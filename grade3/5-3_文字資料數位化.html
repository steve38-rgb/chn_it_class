文字如何在電腦裡住下來？
當你在鍵盤上按下「A」，電腦收到的不是字母，而是一串數字。電腦把所有的文字、符號都 對應到唯一的數字編號，再轉為二進位儲存。這套對應規則，稱為編碼系統。
每個字元都有一個唯一的「碼點（Code Point）」
碼點轉為二進位後存入記憶體
顯示時再由碼點查字型（Font）取得字形
不同編碼系統無法混用，否則產生「亂碼」

英語的捷徑：ASCII 碼
ASCII（American Standard Code for Information Interchange）是電腦最早期的文字編碼，1963 年由美國制訂。
使用 7 位元（0-127）定義 128 個字元，加上擴充後為 8 位元（256 個字元）
包含：英文大小寫（A-Z, a-z）、數字（0-9）、標點符號、控制字元
大寫 A = 65、小寫 a = 97，差 32（剛好方便換算）
數字「0」的碼點 = 48，而非真正的 0
ASCII 只有英語符號，無法表示中文、日文等其他語系

中文編碼的守護者：Big-5
ASCII 只有 256 個碼點，根本不夠表示中文。1984 年，台灣資訊工業策進會制訂 Big-5（大五碼），以 2 個 Byte（16 位元）表示一個中文字。
16 位元 = 最多 65,536 種組合，容納 3 萬多常用繁體字
中文字 A440₁₆ = 「一」；A441₁₆ = 「乙」
主要在台灣、香港（繁體）使用
常見問題：罕見字（如：旁邊的「瑜」字稍冷僻時），搜尋不到字碼
與其他編碼混用時可能出現「亂碼」（如在 Windows 看簡體頁面）

通向全世界：Unicode 萬國碼
1991 年，Unicode 聯盟制訂了全球通用的文字標準。目標：讓每種語言的每個文字，都有唯一的碼點，永不衝突。
最初 16 位元（BMP 基本多文種平面），後擴充至 21 位元
目前已收錄 150,000+ 個字元，涵蓋 150+ 種語言
包含：漢字（CJK）、阿拉伯文、希臘文、表情符號（Emoji）
常見實作格式：UTF-8（英文 1 byte，中文 3 byte，最節省）
UTF-8 完全相容 ASCII，是現在網頁的標準編碼
