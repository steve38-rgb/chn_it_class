# 資科補充 HUB - 教學入口網站

這是一個專為國中資訊科技課堂打造的教學入口與資源中心。網站整合了跨年級的簡報資源、常用教學連結及自製互動工具，旨在提升課堂品質與學習效率。

## 🏫 網站導覽 (Directory)

### 📌 首頁功能
- **教學入口**：集中管理 Gmail、學務系統、OpenID 與 Scratch 捷徑。
- **課堂規定**：明確列出上課前、下課前的設備檢查與維護規範。
- **動態公告**：整合近期與過往的資訊教育活動資源。

### 📖 教學簡報 (Curriculum)
所有簡報均採用現代化、深色視效且支援行動裝置的自動翻頁模板，並內建高品質 SVG 互動插圖。

#### 一年級：資訊社會與法律
- **4-1 個人資料的定義**：辨識個資範疇與直接/間接識別。
- **4-2 個人資料的保護措施**：個資法保障的五大權利與保護意識。
- **4-3 資訊安全與防範措施**：了解資安 CIA 三要素與自我防護。
- **6-1 數位著作的意義**：認識著作權的價值、人格權與財產權。
- **6-2 著作合理使用的判斷**：學習四項合理使用判斷準則。
- **6-3 著作利用的其他建議**：創用 CC 授權與自由軟體資源探索。

#### 三年級：資料數位化
- **5-1 數位化的概念**：類比 vs 數位，採樣、量化與編碼。
- **5-2 數字系統**：進位制轉換（二進位、八進位、十六進位）與互動小遊戲。
- **5-3 文字資料數位化**：ASCII, Big5 與 Unicode 的演進。
- **5-4 & 5-5 影音數位化與 AI 應用**：像素、聲波數位化及當前 AI 技術趨勢。

### 🔧 學習工具 (Tools)
- **雲端資源**：透過 Google Sheets 動態同步最新教學連結與工具下載。
- **本地互動工具**：提供數學與資訊相關的即時運算工具（如：一元一次不等式、指數律工具等）。

---

## 💎 技術特色
- **沉浸式體驗**：全網頁採用深色視覺設計，大幅降低長時間看螢幕的疲勞感。
- **離線可用性**：教學簡報均採單獨 HTML 封裝，內建所有樣式與腳本，無網路環境亦可流暢教學。
- **響應式技術**：自動適應不同螢幕尺寸，從電子白板到個人平板皆有最佳顯示效果。
- **高性能動畫**：使用 `requestAnimationFrame` 與硬體加速，確保簡報翻頁滑順。
